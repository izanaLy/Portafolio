# Instrucciones para asistentes de código

Propietario profesional: Gustavo Pacheco Carballo. Cuenta GitHub: izanaLy.

Objetivo: portafolio profesional IT, Software y Data con entregables reales.

1. Nunca inventar fechas de proyectos, empleo, certificaciones, métricas ni títulos.
2. Los 90 registros en projects.json son ideas pendientes, no trabajo completado.
3. Trabajar en ramas separadas, documentar cambios y preferir pull requests.
4. Para cada proyecto: README, instrucciones de ejecución, pruebas, evidencias y fecha real.
5. No publicar datos personales, CV privados, tokens ni secretos.
6. No realizar gastos, envíos de postulaciones ni despliegues de pago sin autorización.
7. Priorizar primero 3 proyectos demostrables: IT ticket triage, software help desk, data support metrics.
8. No modificar otros repositorios sin autorización.
